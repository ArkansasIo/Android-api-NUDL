# Noodle IDE Android Source

This directory contains the Android client source for **Noodle IDE 1.5.0-pre-alpha**.

- Build ID: `NUDL-NOODLE-1.5.0-PRE-ALPHA-TEST1`
- Developer: `Stephen Jr`
- Target: Android 10+ / ARM64 (P20 Pro first)
- Source of truth: `ArkansasIo/NUDL-IDE` Android integration

The Android project includes the Noodle startup/boot screen, API client, repository/view-model layer, editor UI, diagnostics, and instrumentation tests.
